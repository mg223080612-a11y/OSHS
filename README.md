# OSHS

글로벌선진학교 문경캠퍼스 청소년예술제 — **Our Story, His Story** 웹사이트

- 공연일: 2026.11.21 (SAT) · Coming Soon
- 빌드 없이 동작하는 정적 사이트입니다. `index.html` 을 브라우저로 열면 바로 보입니다.

| 파일 | 내용 |
|---|---|
| `index.html` | 페이지 전체 (메뉴 · 작품 목록 · 시놉시스 · 정보) |
| `styles.css` | 디자인. 색은 맨 위 `:root` 토큰에서 바꿉니다 |
| `main.js` | 공연일 카운트다운, 메뉴 열기/닫기, 지금 보는 섹션에 메뉴 밑줄 표시, 영상 재생 |
| `i18n.js` | 7개 언어 번역 (탭 제목 포함) |

섹션마다 역할이 하나씩입니다. 같은 정보를 여러 곳에 반복하지 마세요.

| 섹션 | 역할 |
|---|---|
| 메인 화면 | 제목 · 홍보 문구 · D-DAY · 카운트다운 (카운트다운은 여기에만) |
| Production | 포스터 + 가려면 필요한 정보 (일시 · 장소 · 오시는 길 · 예매) |
| Story | 줄거리 |
| History | 지난 공연 영상 |

러닝타임 · 관람 안내가 정해지면 `index.html` 의 Production 안 주석을 풀어 채우세요.
